# iamirhosein.ir

سایت شخصی و نمونه‌کار امیرحسین کهن‌سال. سایت ایستا است (HTML و CSS و JavaScript ساده)، مرحله‌ی build ندارد و GitHub Pages مستقیم همین فایل‌ها را نمایش می‌دهد.

## ساختار پوشه

```
index.html            صفحه‌ی اصلی، متن‌های فارسی همین‌جاست
404.html              صفحه‌ی «پیدا نشد»
css/style.css         ظاهر سایت (رنگ‌ها در بالای فایل، بخش tokens)
js/projects.js        ← نمونه‌کارها (برای افزودن پروژه فقط این را ویرایش کنید)
js/config.js          ← ایمیل، تلگرام، واتس‌اپ، لینکدین، گیت‌هاب و فهرست مهارت‌ها
js/i18n.js            متن‌های نسخه‌ی انگلیسی
js/main.js            منطق صفحه (تغییر زبان، حالت تیره، ساخت کارت‌ها، فرم سفارش)
assets/               فونت وزیرمتن، آیکن، تصویر Open Graph و تصویر پروژه‌ها
CNAME                 دامنه‌ی سفارشی (iamirhosein.ir)
portfolio/*/          نشانی‌های قدیمی که لینکدین به آن‌ها لینک داده؛ به کارت همان پروژه هدایت می‌کنند
```

## قبل از انتشار

۱. **`js/config.js`** را باز کنید و هر مقداری را که با `REPLACE_ME` شروع شده، با اطلاعات خودتان عوض کنید. لینکی که خالی (`""`) بماند روی سایت نمایش داده نمی‌شود. دکمه‌ی «ارسال در تلگرام» فرم هم فقط وقتی ظاهر می‌شود که یوزرنیم تلگرام را وارد کرده باشید.

۲. در **`js/projects.js`** لینک App Store هر اپی که منتشر شده را در `appStore` بگذارید (الان هیچ‌کدام لینک ندارد) و اگر تصویر دارید، در `image`. پروژه‌ها از پروفایل لینکدین گرفته شده‌اند.

۳. املای نام فارسی («امیرحسین کهن‌سال») در `index.html` آمده است؛ اگر املای دیگری را ترجیح می‌دهید، با جست‌وجو و جایگزینی عوضش کنید.

## پیش‌نمایش روی کامپیوتر خودتان

در پوشه‌ی پروژه این دستور را اجرا کنید و نشانی `http://localhost:8000` را در مرورگر باز کنید:

```bash
python3 -m http.server 8000
```

## انتشار روی GitHub Pages

### ۱. ساخت مخزن در GitHub

دو راه دارید:

- **مخزن به نام `<username>.github.io`** (مثلاً `iamirhosein.github.io`). این مخزن سایت اصلی حساب شماست.
- **هر مخزن دیگری** (مثلاً `portfolio`). Pages روی هر مخزنی فعال می‌شود و با دامنه‌ی سفارشی فرقی برای بازدیدکننده ندارد.

در github.com روی **New repository** بزنید، نام را وارد کنید، آن را **Public** بگذارید (Pages رایگان فقط برای مخزن عمومی است) و **هیچ فایلی** (README یا license) اضافه نکنید.

### ۲. فرستادن کد

به‌جای `<username>` و `<repo>` نام کاربری و نام مخزن را بگذارید:

```bash
git add -A
git commit -m "first version of the portfolio site"
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

### ۳. روشن کردن Pages

در مخزن به **Settings ← Pages** بروید:

- **Source**: گزینه‌ی *Deploy from a branch*
- **Branch**: `main` و پوشه‌ی `/ (root)`، بعد **Save**
- در بخش **Custom domain** باید `iamirhosein.ir` نوشته شده باشد (از فایل `CNAME` خوانده می‌شود). اگر خالی بود، خودتان بنویسید و Save کنید.

چند دقیقه بعد سایت روی `https://<username>.github.io/<repo>/` بالا می‌آید و بعد از تنظیم DNS روی دامنه‌ی خودتان.

### ۴. تنظیم DNS دامنه‌ی ‎.ir

رکوردهای DNS را در پنل سرویسی تنظیم کنید که DNS دامنه را میزبانی می‌کند. در nic.ir فقط nameserverها تعیین می‌شوند؛ رکوردها در پنل همان سرویسی ثبت می‌شوند که nameserverها به آن اشاره می‌کنند (مثلاً Cloudflare یا پنل شرکتی که دامنه را از آن خریده‌اید). اگر الان رکوردی برای `iamirhosein.ir` هست که به سرور نمونه‌ی فعلی اشاره می‌کند، اول آن را حذف کنید.

**دامنه‌ی اصلی (`iamirhosein.ir`)**، چهار رکورد A:

| نوع | نام | مقدار |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |

اختیاری، برای IPv6، چهار رکورد AAAA:

| نوع | نام | مقدار |
|---|---|---|
| AAAA | @ | 2606:50c0:8000::153 |
| AAAA | @ | 2606:50c0:8001::153 |
| AAAA | @ | 2606:50c0:8002::153 |
| AAAA | @ | 2606:50c0:8003::153 |

**زیردامنه‌ی `www`**، یک رکورد CNAME:

| نوع | نام | مقدار |
|---|---|---|
| CNAME | www | `<username>.github.io` |

(فقط نام کاربری، بدون نام مخزن.) GitHub خودش `www.iamirhosein.ir` را به `iamirhosein.ir` هدایت می‌کند.

اگر از Cloudflare استفاده می‌کنید، تا وقتی گواهی HTTPS صادر نشده ابر نارنجی (Proxy) را برای این رکوردها خاموش بگذارید (حالت *DNS only*).

برای بررسی، بعد از چند دقیقه تا چند ساعت:

```bash
dig iamirhosein.ir +short
```

باید چهار IP بالا را نشان دهد.

### ۵. روشن کردن HTTPS

وقتی DNS درست شد، در **Settings ← Pages** پیام *DNS check successful* را می‌بینید. GitHub گواهی Let's Encrypt را خودکار صادر می‌کند (ممکن است تا یک ساعت طول بکشد). بعد گزینه‌ی **Enforce HTTPS** را تیک بزنید.

اگر این گزینه خاکستری ماند، Custom domain را پاک کنید، Save بزنید، دوباره `iamirhosein.ir` را بنویسید و Save کنید تا GitHub دوباره برای گواهی اقدام کند.

### ۶. (پیشنهادی) تأیید دامنه در GitHub

در **Settings حساب کاربری ← Pages ← Add a domain**، دامنه را اضافه کنید و رکورد TXT که GitHub می‌دهد را در DNS بگذارید. این کار جلوی این را می‌گیرد که کس دیگری دامنه‌ی شما را روی مخزن خودش ببندد.

## افزودن پروژه‌ی جدید

۱. تصویر پروژه را (ترجیحاً ۱۲۰۰×۷۵۰ پیکسل) در `assets/projects/` بگذارید، مثلاً `assets/projects/my-app.png`.

۲. در `js/projects.js` یک شیء تازه به آرایه اضافه کنید. ساده‌ترین راه کپی کردن یکی از پروژه‌های موجود است:

```js
  {
    id: "my-app",
    year: 2026,
    title: { fa: "نام اپ", en: "App name" },
    role: { fa: "توسعه‌دهنده‌ی iOS", en: "iOS developer" },
    description: {
      fa: "توضیح کوتاه به فارسی.",
      en: "Short description in English."
    },
    tech: ["Swift", "SwiftUI"],
    image: "assets/projects/my-app.png",
    links: { appStore: "https://apps.apple.com/app/id...", googlePlay: "", github: "", website: "" }
  },
```

بین پروژه‌ها ویرگول (`,`) یادتان نرود. `featured: true` کارت را بزرگ‌تر و اول نشان می‌دهد؛ `placeholder: true` برچسب «نمونه» می‌زند.

۳. فایل را ذخیره کنید، با `python3 -m http.server 8000` پیش‌نمایش ببینید و بعد:

```bash
git add -A
git commit -m "add my-app to portfolio"
git push
```

یکی دو دقیقه بعد تغییر روی سایت دیده می‌شود.

## تغییر متن‌ها

- متن فارسی: مستقیم در `index.html`.
- متن انگلیسی: در `js/i18n.js`، با همان کلیدی که در `data-i18n` عنصر فارسی آمده است.
- عنوان و توضیح سئو و Open Graph: بخش `<head>` در `index.html`. تصویر پیش‌نمایش لینک‌ها `assets/og-image.png` است (۱۲۰۰×۶۳۰).
